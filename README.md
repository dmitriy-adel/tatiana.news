## Пользовательское соглашение 

### 1. Общие положения
1.1. Основные термины и определения
1.1.1. Сервис — агрегатор новостных статей под наименованием tatiana.news, расположенный в сети Интернет по адресу http://localhost:8001.

1.1.2. Пользователь — любое физическое или юридическое лицо, осуществляющее доступ к Сервису.

1.1.3. Контент — новостные статьи, заголовки, описания, изображения и иные материалы, агрегируемые Сервисом.

1.2. Предмет Соглашения
Настоящее Соглашение определяет условия предоставления Пользователю права на использование сервиса tatiana.news как агрегатора новостных статей.

1.3. Акцепт Соглашения
Использование Сервиса любым способом означает полное и безоговорочное принятие условий настоящего Соглашения.

1.4. Изменение Соглашения
Администрация Сервиса вправе в любое время изменять условия Соглашения. Новая редакция вступает в силу с момента публикации на Сервисе. Продолжение использования Сервиса после изменений означает согласие с новой редакцией.

1.5. Применимое законодательство
Настоящее Соглашение регулируется законодательством Российской Федерации.

### 2. Правила использования сервиса
2.1. Доступ к сервису
Доступ к Сервису предоставляется бесплатно и без обязательной регистрации.

2.2. Права пользователей
Просматривать агрегированный контент и переходить по ссылкам на первоисточники
Использовать поиск по новостям
Сохранять ссылки на статьи для личного использования
2.3. Обязанности пользователей
Соблюдать условия настоящего Соглашения и законодательство РФ
Не нарушать работу Сервиса
Уважать права интеллектуальной собственности
2.4. Запрещённые действия
Пользователю запрещается:

Использовать Сервис в коммерческих целях без разрешения
Копировать Контент в больших объёмах
Пытаться обходить технические средства защиты
Создавать чрезмерную нагрузку на Сервис
2.5. Интеллектуальная собственность
Все права на Контент принадлежат соответствующим правообладателям. Сервис tatiana.news только агрегирует и предоставляет ссылки на открытые источники. Пользователь не получает никаких прав на интеллектуальную собственность Контента, кроме права просмотра.

2.6. Ограничение ответственности
Сервис предоставляется «как есть». Администрация не гарантирует бесперебойную работу Сервиса и не несёт ответственности за достоверность, полноту и актуальность агрегируемых новостей.

Администрация не несёт ответственности за содержание внешних ресурсов, на которые ведут ссылки с Сервиса.

2.7. Прекращение использования
Пользователь вправе в любое время прекратить использование Сервиса. Администрация вправе ограничить или прекратить доступ к Сервису в случае нарушения условий Соглашения.
